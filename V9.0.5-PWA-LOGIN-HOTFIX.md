# V9.0.5 PWA Login Hotfix

- Fixed the iPhone/iPad Add to Home Screen login crash caused by dashboard greeting elements not existing in the standalone app shell.
- User name, greeting, role, and account labels now update only when their elements are present.
- Hardened the login gate for cached or partially loaded PWA pages.
- Bumped the operations app build to 905 to force the standalone app to refresh its cached JavaScript.
