# V9.0.7 Automatic Operations Alerts

- Added a Netlify scheduled function that runs every five minutes, even when the Operations Hub is closed.
- Sends a separate field-open notification after each field's final scheduled game, using configurable game-duration and cleanup-buffer settings.
- Added NWS thunderstorm/lightning-danger alerts, heavy-rain alerts, and dangerous-wind alerts.
- Added owner-only server-persisted automation settings under Notifications > Notification Management.
- Prevents duplicate alerts by recording every field/date/matrix-version and weather alert already sent.

Note: lightning risk uses official thunderstorm alerts and reported conditions. It is not a commercial strike-level lightning detector.
