# V8.2.1 — Notifications Security Fix

Fixes notification history, push enrollment, refresh, access settings, and alert
sending when an Owner is using a remembered device.

## Fixed

- Notification requests now use the Operations Hub shared authenticated API.
- Remembered-device and Owner verification tokens are included automatically.
- A genuine expired verification opens the normal email-code modal and retries.
- Removed the permanent red security-code error behavior.
- Notification startup now waits for the signed-in profile to finish loading.
- Push enrollment no longer fails just because the notification script started
  before the Owner security session was ready.

## Install

No Supabase SQL is required.

1. Upload the unzipped project to Netlify.
2. Choose Clear cache and deploy site.
3. Hard-refresh the Operations Hub.
4. Open Notifications and press Refresh.
5. Re-enroll the device only if the browser still shows it as not enrolled.
