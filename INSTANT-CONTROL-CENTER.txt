Adventure Sports Instant Control Center

The greeting uses the signed-in Netlify Identity user's first name.
If no name is saved, it uses the readable part of the email; otherwise Administrator.

Quick Edit changes for site, rentals, clubhouse and safety go live immediately through Netlify Blobs.
GitHub is still updated in the background for backup and rollback.

Photos, event uploads and code/layout changes still use a normal Netlify deployment.

Install:
1. Replace all repository files with this package.
2. Commit and push.
3. Wait for this one Netlify deploy.
4. Hard refresh /admin/ with Command + Shift + R.
