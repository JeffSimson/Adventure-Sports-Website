V7.1 NETLIFY SECRET-SCAN FIX

This package keeps all private credentials in Netlify environment variables.
The only AIza value in the frontend is the Firebase browser API key, which is a public client identifier required by Firebase Messaging. netlify.toml now tells Netlify Smart Detection to omit that exact public value.

DO NOT commit any of these actual secret values:
- FIREBASE_SERVICE_ACCOUNT_JSON
- GITHUB_TOKEN
- NETLIFY_AUTH_TOKEN
- CLOVER_ACCESS_TOKEN

After replacing the repository files, commit and push. Netlify should deploy normally.
If Netlify still reports a different value, open the failed deploy and identify the exact file/path before allowing it.
