# V9.2.1 — Live Game Day Control Center

## Included

- Live game statuses: Upcoming, In Progress, Delayed, Complete, and Canceled
- Move an individual game to another active field and/or time
- Delay every remaining game by 15, 30, or 60 minutes
- Lightning hold, timer restart, clear-period completion, and management-confirmed reopening
- Field cleanup and setup-change tracking
- One-tap push and public-website updates for management, staff, all enrolled devices, or teams/public
- Public live game-day status board on adventurenj.com
- Full audit history showing who changed what and when
- Operations Center cards for today’s games, fields in use, fields opening soon, delayed games, active weather alerts, overdue work orders, field readiness, and Clover status
- Matrix-connected automatic alerts for field release, first-game preparation, final-game reminders, schedule changes, and lightning clearance
- Responsive iPhone/Home Screen app layouts and contained horizontal table scrolling
- System Tests coverage for Game Day Control readiness

## Deliberately not included

- Grounds-staff assignment to individual fields

## Deployment

Upload the full ZIP to Netlify. Confirm the Operations Hub sidebar reads **V9.2.1**. Then fully close and reopen the Home Screen app so build **9210** replaces the old cached files.
