# Adventure Sports V9.0 — Operations Command Center

## Implemented

- Mobile-first role-based Home dashboards
- Owner-controlled dashboard visibility by role
- Individual employee dashboard exceptions by email
- Automatic clean dashboard layout (no dragging)
- Command Palette with Command-K / Control-K and mobile search button
- Schedule tab connected directly to `content/events.json` used by the public website
- Upcoming event agenda
- Monthly event calendar
- Event detail viewer and registration links
- Existing games and field matrix preserved inside Schedule
- Navigation renamed and simplified
- Existing Fields, Work Orders, Equipment, Employees, Incidents, Notifications, Clover, Weather, Security, and Inventory functionality preserved

## Important

Inventory behavior was intentionally left unchanged. No new Supabase migration is required.
