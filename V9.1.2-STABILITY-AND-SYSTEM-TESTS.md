# Adventure Sports Operations Hub V9.1.2

## Stability and testing update

- Added an owner-only **System Tests** tab inside Settings.
- Added live checks for Supabase, Netlify storage, push enrollment, PWA files, Clover, weather providers, work orders, the live tournament matrix, and the automatic-alert scheduler.
- Added safe no-live-data simulations for tournament matrix create/edit/copy/publish/delete, duplicate-alert suppression, and the lightning-clear timer.
- Strengthened automatic-alert duplicate protection by reserving alert keys before delivery and preventing overlapping scheduled runs.
- Added last-run, last-success, error, result, lightning-state, and dedupe-key diagnostics for the automatic alert worker.
- Added mobile containment, 44-pixel touch targets, scrollable internal tabs, and isolated horizontal scrolling for wide tables.
- Bumped the PWA build marker, manifest, scripts, styles, and service worker to build `9120`.

## Deploy

Upload this ZIP to Netlify. After deployment, confirm the sidebar displays **V9.1.2**. Fully close and reopen the Home Screen app once. Owners can open **Settings → System Tests** and press **Run Full System Test**.
