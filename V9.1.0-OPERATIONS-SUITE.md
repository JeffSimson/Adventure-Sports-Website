# Adventure Sports Operations Hub V9.1.0

## Tournament Management
- Create, edit, save, delete, archive, restore, and publish tournament matrices.
- Choose tournament dates and included fields.
- Add, remove, and edit game times.
- Assign fields separately to every game time.
- Copy the previous day's complete schedule.
- Import TXT, CSV, XLS, or XLSX schedules into the visual editor.
- Mobile editor with horizontally scrollable live matrices and compact controls.

## Matrix-driven Auto Ops Alerts
- Field-open notification after each field's final game and cleanup buffer.
- First-game preparation reminder.
- Final-game reminder.
- Live schedule-change notification after publishing.
- Lightning-risk notification and configurable lightning-clear reopening notice.

## Operations Center
- Today's tournament game count.
- Fields currently in use.
- Fields expected to open soon.
- Active official weather alerts.
- Open and overdue work orders.
- Clover connection status.

## iPhone and Home Screen App
- Contained page widths to prevent whole-page sideways overflow.
- Wide tables and tournament matrices scroll inside their own sections.
- Mobile tournament builder layouts and touch-friendly controls.
- Build marker and no-cache refresh checks for installed Home Screen apps.

## Deployment
Upload the contents of this ZIP as the Netlify site. After deployment, confirm the sidebar version badge displays **V9.1.0**. Fully close and reopen the installed Home Screen app once after deployment.
