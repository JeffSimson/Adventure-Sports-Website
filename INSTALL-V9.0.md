# Install V9.0

1. Unzip the package.
2. Upload the full unzipped project to Netlify.
3. Choose **Clear cache and deploy site**.
4. Hard-refresh the Operations Hub.
5. Sign in as Owner.
6. Open **Settings → Dashboard & Role Visibility** to choose dashboard cards for each role or enter an employee email for an individual exception.
7. Test Owner, Manager, Grounds, Kitchen, and Cashier accounts.

No Supabase SQL is required for this release.
