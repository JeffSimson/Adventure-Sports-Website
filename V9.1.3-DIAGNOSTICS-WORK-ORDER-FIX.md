# V9.1.3 — Diagnostics and Work Order Compatibility Fix

## Fixed

- Work-order diagnostics no longer query a nonexistent `due_at` column.
- Existing Supabase work orders now use `scheduled_end` as the deadline, with compatibility for older `due_at` records.
- Operations Center overdue-work-order cards load from the real work-order schema.
- Automatic overdue-work-order alerts use the same compatible deadline logic.
- A day with no tournament games is reported as a healthy zero-game state instead of a warning.
- Automatic-alert diagnostics can confirm delivery from notification history while the new five-minute scheduler heartbeat is initializing.
- Work-order create/edit fields now match the current database schema.
