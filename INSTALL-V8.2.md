# Install V8.2

1. In Supabase SQL Editor, run `supabase/migrations/008-security-devices-incidents.sql`.
2. Upload the unzipped V8.2 project to Netlify.
3. Choose **Clear cache and deploy site**.
4. Hard-refresh the Operations Hub.
5. Complete one Owner email code and remember the device.
6. Open Settings → Enterprise Security Center to manage trusted devices.
7. Open Database Center → Incident Reports to use Incident Reports 2.0.

Do not reset Supabase or rerun earlier migrations.
