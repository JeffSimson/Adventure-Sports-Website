# V8.1.2 — Trusted Device Fix

Fixes the issue where an Owner could check **Remember this device for 30 days**
but still receive the verification popup immediately after signing back in.

## What changed

- The saved 30-day trusted-device token now uses the same established security
  header path as the normal 8-hour verification token.
- Backend verification accepts either valid token type.
- The dedicated trusted-device header is still sent as a fallback.
- Cache build updated to 812.

## Install

No new Supabase SQL is required.

1. Upload the unzipped project to Netlify.
2. Use **Clear cache and deploy site**.
3. Hard-refresh the app.
4. Complete one email verification and check **Remember this device for 30 days**.
5. Sign out and sign back in using a normal browser window.
