# Adventure Sports V8.0 Enterprise Security Edition

## Included
- Email-only Owner step-up verification through Resend
- Server-side account, role, permission, and maintenance-mode enforcement
- Owner panic lock that revokes all Owner step-up sessions
- Manual database snapshot backups and protected JSON downloads
- Append-only security event protection
- Security dashboard with configuration, database health, events, and backups
- Strong CSP, HSTS, frame protection, referrer policy, and no-store headers
- Write rate limits, request size controls, table allowlists, and column allowlists
- Auditing for generic database create/update/delete operations

## Deployment order
1. Keep V7.5.1 live until Resend DNS is verified.
2. Run `supabase/migrations/005-security-hardening.sql` if not already run.
3. Run `supabase/migrations/006-enterprise-security.sql`.
4. Confirm Netlify variables: `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`, `SECURITY_SESSION_SECRET`, `RESEND_API_KEY`, `SECURITY_EMAIL_FROM`, and your Owner email variable.
5. Deploy this ZIP with **Clear cache and deploy site**.
6. Sign in as Owner, verify by email, open Settings, and create the first backup.
7. Test each role before normal use.

## Important limitations
This is a substantial hardening release, not a penetration-test certification. Netlify Identity sessions themselves are managed by Netlify. Panic Lock immediately invalidates Owner step-up tokens; users may still need to sign out of their underlying Identity session. Backup snapshots are capped at 5,000 rows per included table and should supplement—not replace—Supabase managed backups.
