# Adventure Sports Operations Hub V7.4.1

## Included
- Clover tips now match employees through both payment records and associated orders.
- Clover employee directory is loaded and used to resolve employee IDs to names.
- Owner diagnostics show tipped payments checked, employees readable, and unmatched payments.
- New Owner-only Database Center under Settings.
- Database Center supports viewing, searching, adding, editing, and deleting approved operational records.
- New Clover employee mapping database table and secure owner-only Netlify function.

## Supabase installation
Run this one new migration after deploying the files:

`supabase/migrations/004-clover-mapping-database-center.sql`

Do not reset or delete the existing Supabase database.
