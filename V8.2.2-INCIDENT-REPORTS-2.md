# V8.2.2 — Incident Reports 2.0

- Six-step guided incident form
- Individual people cards instead of raw JSON
- Before / during / after timeline
- Emergency response switches
- Actions-taken checklist
- Follow-up and manager review workflow
- Automatic local draft saving
- Professional report viewer
- Print / Save PDF
- Automatic IR-year-number display
- No photo upload option

## Install
1. Run `supabase/migrations/008-incident-reports-2.sql`.
2. Upload the unzipped project to Netlify.
3. Clear cache and deploy.
4. Hard-refresh the Operations Hub.
