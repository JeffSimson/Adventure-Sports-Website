# V8.0.1 Authentication Hotfix

Fixes the Owner sign-in failure that displayed `error is not a function` and caused `auth-profile` to return HTTP 500.

## Root cause

The Supabase helper imported the error helper from the role-auth module while role-auth also imported Supabase. That circular dependency could leave the error helper undefined when a database request failed.

## Fix

- Removed the circular dependency.
- Added a standalone database error helper.
- Preserved safe HTTP status codes and messages.
- Updated browser cache references to V8.0.1.

No new SQL migration is required for this hotfix. Existing V8 migrations 005 and 006 must already be installed.
