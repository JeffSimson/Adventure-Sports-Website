# V8.1.3 — Trusted Device All-Modules Fix

This fixes the remaining issue where the Owner dashboard accepted a remembered
device, but Database Center and other sensitive modules still opened the email
verification popup.

## Cause

The main profile request accepted the trusted-device token, but the shared
Database Center code only received the short 8-hour token.

## Fix

- Sensitive modules now receive either the short verification token or the
  saved 30-day trusted-device token.
- The security check now recognizes a remembered device before opening a modal.
- Build cache updated to 813.

## Install

No Supabase SQL is required.

1. Upload the unzipped project to Netlify.
2. Use Clear cache and deploy site.
3. Hard-refresh the Operations Hub.
4. Complete one email code and check Remember this device for 30 days.
5. Sign out and back in.
