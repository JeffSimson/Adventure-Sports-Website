# Adventure Sports V10.0.0 — Event Management + Registration Engine

## What changed
- New **Events & Signups** module inside the Operations Hub.
- Full event editor for title, descriptions, category, sport, dates/times, location, divisions, pricing display, contacts, media URLs, SEO, admission, rules, waiver links, featured/public state, and internal notes.
- Event registration modes: **Adventure Signup**, **External Registration**, or **No Registration**.
- Adventure Signup supports **Team** and **Individual** registrations.
- Per-event capacity, automatic registration dates, forced open/closed state, waitlist, divisions, and custom registration questions.
- Registration management: view, edit, change status, cancel, delete (Owner), and CSV export.
- One-click **Import Current Website Events** migrates `/content/events.json` into Supabase without deleting the JSON fallback.
- Public events now read from Supabase automatically after migration/import, with the existing JSON file retained as a safe fallback.
- Every database-backed public event gets its own `/event.html?event=...` detail page.
- Internal signup forms do **not** process payment in V10.0.0.

## One-time setup
1. Deploy the V10.0.0 patch files to the website.
2. Open Supabase → SQL Editor.
3. Run the complete `EVENT-ENGINE-SETUP.sql` file once.
4. Open Adventure Sports Operations Hub → **Events & Signups**.
5. Press **Import Current Website Events**.
6. Edit any imported event and choose its registration method.

## Safe migration behavior
- This patch does **not** overwrite `content/events.json`.
- Existing event links continue working because imported events default to their current external registration link.
- Switch an event to **Adventure Signup** only when you want the new internal registration form.
- Published database edits update the public site without a GitHub commit or Netlify redeploy.
