# V8.2.3 — Incident Reports Tab Quick Fix

## Fixed
- Incident report viewer can now always be closed with the X, backdrop, or Escape key.
- Added a dedicated Incident Reports tab in the main navigation.
- Every signed-in employee can create and submit a new incident report.
- View All Reports is visible only to Owners and Managers.
- Saved incident reports can only be listed or edited by Owners and Managers.
- Employees who submit reports cannot browse confidential report history.

## Install
No new Supabase migration is required.

1. Upload the unzipped project to Netlify.
2. Choose Clear cache and deploy site.
3. Hard-refresh the Operations Hub.
4. Test the Incident Reports tab with an Owner/Manager and a regular employee account.
