# V8.1.1 — Remember This Device

Adds an optional **Remember this device for 30 days** checkbox to Owner email verification.

- Checked: no additional email code on this browser for 30 days.
- Unchecked: the normal 8-hour Owner verification session is used.
- Normal logout keeps the remembered-device approval.
- Incognito/private browsing usually loses it when the window closes.
- Panic Lock or a security session reset revokes it immediately.
- Use only on a personal, password-protected device.

No new Supabase migration is required.
Upload the unzipped project to Netlify and use **Clear cache and deploy site**.
